# Slovora - сербский языковой тренажер

Slovora - небольшое single page app для тренировки сербской грамматики и словаря через упражнения с карточками. Интерфейс поддерживает подсказки на английском и русском родном языке; по умолчанию используется английский.

## Архитектура

Приложение специально оставлено легковесным:

- Frontend: vanilla JavaScript ES modules, HTML и CSS.
- Роутинг: hash routes вроде `#menu`, `#exercise/biti-short-basic`, `#false-friends` и `#readme`.
- Runtime data: JSON-файлы, которые браузер загружает из `data/`.
- Exercise engine: генерация, подсказки и проверка ответов находятся в `src/engine/`.

Slovora использует concept ID, чтобы связывать сербские лексемы с подписями на родном языке. Сербский лексикон в `data/languages/sr/lexicon.json` хранит формы и грамматические метаданные. Файлы концептов `data/languages/native/en/concepts.json` и `data/languages/native/ru/concepts.json` дают текст подсказок для тех же концептов.

## Локальный запуск

Так как приложение использует ES modules и `fetch()`, запускайте его через локальный статический сервер из корня проекта:

```bash
python -m http.server 8000
```

Потом откройте `http://localhost:8000`.

## Обновление данных

CSV-пайплайна больше нет. Данные редактируются напрямую в JSON:

- Сербские лексемы и формы: `data/languages/sr/lexicon.json`
- Таблицы грамматической справки: `data/languages/sr/grammar.json`
- Концепты родного языка: `data/languages/native/en/concepts.json` и `data/languages/native/ru/concepts.json`
- Строки интерфейса: `data/ui/en.json` и `data/ui/ru.json`

Упражнение на указательную конструкцию намеренно ограничено вариантом `ovo` / `this` / `это`. Дистанционные указательные конструкции сейчас не используются.

## Ложные друзья

Русскоязычная мини-игра False Friends использует `data/languages/sr/falsefriends.json`. Она собирает раунды из сгруппированных пар, избегает пересечений по смыслу внутри раунда, поддерживает split pairs для омонимов и показывает заметки через режим подсказок.

## Тесты и логи

Основной test runner генерирует случайные задания, проверяет грамматику и правила валидации ответов, а затем записывает примеры в `tests/exercise_log.json`:

```bash
node tests/test_runner.js
```

Чтобы посмотреть случайную выборку из последнего лога упражнений:

```bash
python tools/sample_logs.py
```

Эти файлы нужно сохранять: test runner и просмотр случайных логов - текущий цикл проверки качества сгенерированных заданий.

## Структура проекта

- `data/` - JSON-данные, которые загружает браузер.
- `src/app.js` - точка входа и hash router.
- `src/engine/` - загрузка лексикона, генерация упражнений, сборка подсказок и проверка.
- `src/ui/` - меню, упражнения, настройки, статистика, справка, False Friends и экран README.
- `tests/test_runner.js` - проверка случайных упражнений.
- `tests/exercise_log.json` - лог сгенерированных упражнений для ревью.
- `tools/sample_logs.py` - просмотр случайной выборки из лога.
- `README.md` - английский README.
- `README.ru.md` - русский README.
