# Множественное число в сербском языке

## 1. Мужской род

**Базовое правило:** если слово мужского рода заканчивается на согласную, во множественном числе оно получает окончание **-и (-i)**.

### 1.1. Заднеязычные согласные: К (K), Г (G), Х (H)

Если слово мужского рода заканчивается на заднеязычные согласные **К (K), Г (G), Х (H)**, то перед окончанием множественного числа **-и (-i)** они всегда меняются на свистящие **Ц (C), З (Z), С (S)**.

| Единственное число | Множественное число | Изменение |
|---|---|---|
| пољак (poljak) | пољаци (poljaci) | К (K) → Ц (C) |
| хирург (hirurg) | хирурзи (hirurzi) | Г (G) → З (Z) |
| монах (monah) | монаси (monasi) | Х (H) → С (S) |

### 1.2. Беглое «А (A)»

**А (A)** выпадает при добавлении окончания, если в слове есть суффикс типа **-ац (-ac)**, **-ак (-ak)** или сочетание типа **-ат (-at)**.

| Единственное число | Множественное число |
|---|---|
| нокат (nokat) | нокти (nokti) |
| старац (starac) | старци (starci) |

### 1.3. Беглое «А (A)» + переход «Л (L)» в «О (O)»

Если исторически буква **Л (L)** стояла в конце слова или в конце слога, она со временем превратилась в **О (O)**, и появилось слово мужского рода с окончанием на **-о (-o)**. Если при изменении слова эта буква снова оказывается перед гласной, она «вспоминает», что была буквой **Л (L)**.

**Пример:** `котао (kotao) → котлови (kotlovi)`

1. Убираем беглую **А (A)**: `котао (kotao) → кото (koto)`.
2. Добавляем окончание **-ови (-ovi)**: `кото (koto) → котоови (kotoovi)`.
3. **О (O)** превращается в **Л (L)**: `котоови (kotoovi) → котлови (kotlovi)`.

Если в слове видно окончание **-лац (-lac)** или **-лак (-lak)**, буква **Л (L)**, наоборот, будет меняться на **О (O)**.

| Единственное число | Множественное число |
|---|---|
| заселак (zaselak) | засеоци (zaseoci) |
| читалац (čitalac) | читаоци (čitaoci) |

**Как происходит изменение:**

1. Добавляем букву **-и (-i)** в конце: `читалаци (čitalaci)`, `заселаки (zaselaki)`.
2. Буква **А (A)** выпадает: `читалци (čitalci)`, `заселки (zaselki)`.
3. **К (K)** меняется на **Ц (C)** либо остается уже существующая **Ц (C)**: `читалци (čitalci)`, `заселци (zaselci)`.
4. **Л (L)** меняется на **О (O)**: `читаоци (čitaoci)`, `засеоци (zaseoci)`.

### 1.4. Выпадение суффикса «-ИН (-IN)»

Правило касается национальностей и жителей городов/регионов, которые в единственном числе заканчиваются на **-ин (-in)**: `Србин (Srbin)`, `Русин (Rusin)` (= `Рус (Rus)`), `Београђанин (Beograđanin)`.

Во множественном числе этот суффикс просто отбрасывается, и добавляется **-и (-i)**.

| Единственное число | Множественное число |
|---|---|
| Србин (Srbin) | Срби (Srbi) |

### 1.5. Резюме по мужскому роду

| Условие | Что происходит | Пример |
|---|---|---|
| Слово заканчивается на **К (K), Г (G), Х (H)** | Меняем на **Ц (C), З (Z), С (S)** | пољак (poljak) → пољаци (poljaci) |
| В конце слова есть суффикс **-ац (-ac)**, **-ак (-ak)** или сочетание типа **-ат (-at)** | Убираем **А (A)** | старац (starac) → старци (starci); нокат (nokat) → нокти (nokti) |
| Слово заканчивается на **-ао (-ao)** или **-ео (-eo)** | Восстанавливаем букву **Л (L)** и убираем **А (A)** | котао (kotao) → котлови (kotlovi) |
| Слово заканчивается на суффикс **-лац (-lac)** | Выпадает **А (A)**, **Л (L)** меняется на **О (O)** | читалац (čitalac) → читаоци (čitaoci) |
| Слово обозначает национальность или жителя и заканчивается на **-ин (-in)** | Отрезаем **-ин (-in)** | Србин (Srbin) → Срби (Srbi) |

## 2. Мужской род: односложные слова

**Короткие слова часто получают длинные окончания:** **-ови (-ovi)** / **-еви (-evi)**.

- Суффикс **-еви (-evi)** используется после мягких согласных: **ј (j), љ (lj), њ (nj), ч (č), ж (ž), ш (š), џ (dž), ђ (đ)**.
- Иногда после **ц (c), з (z), с (s)** тоже ставится **-еви (-evi)**: `нос (nos) → носеви (nosevi)`, `стриц (stric) → стричеви (stričevi)`.
- Но чаще после **ц (c), з (z), с (s)** всё-таки используется **-ови (-ovi)**: `појас (pojas) → појасови (pojasovi)`.
- Выбор зависит от исторического корня слова.
- Суффикс **-ови (-ovi)** ставится после твердых согласных.

| Единственное число | Множественное число |
|---|---|
| син (sin) | синови (sinovi) |
| змај (zmaj) | змајеви (zmajevi) |

### 2.1. Односложные слова с коротким окончанием

Короткое окончание получают определенные смысловые группы односложных слов.

| Группа                    | Примеры                                                                  |
| ------------------------- | ------------------------------------------------------------------------ |
| Части тела                | зуб (zub) → зуби (zubi); прст (prst) → прсти (prsti)                     |
| Единицы времени/измерения | дан (dan) → дани (dani); сат (sat) → сати (sati)                         |
| Национальности/люди       | Грк (Grk) → Грци (Grci); ђак (đak) → ђаци (đaci); гост (gost) → гости (gosti) |
|                           |                                                                          |

### 2.2. Особые случаи

| Единственное число | Множественное число |
| ------------------ | ------------------- |
| брат (brat)        | браћа (braća)       |
| човек (čovek)      | људи (ljudi)        |
| господин (gospodin) | господа (gospoda)  |

Если корень слова заканчивается на букву **Ц (C)**, и к нему приклеивается окончание, начинающееся на гласную **Е (E)**, то буква **Ц (C)** превращается в шипящую **Ч (Č)**, а если **Т (T)** или **Д (D)** стоят перед **Ч (Č), Џ (Dž), Ћ (Ć)** или **Ђ (Đ)** — они полностью исчезают для легкости произношения.

| Единственное число | Множественное число |
| ------------------ | ------------------- |
| зец (zec)          | зечеви (zečevi)     |
| отац (otac)        | очеви (očevi)       |
| стриц (stric)      | стричеви (stričevi) |
| напитак (napitak)  | напици (napici)     |

Конечно есть и другие правила, здесь не представляется возможным перечислить все.

## 3. Средний род

**Базовое правило:** если слово среднего рода заканчивается на **-о (-o)** или **-е (-e)**, во множественном числе оно получает окончание **-а (-a)**.

| Тип окончания | Единственное число | Множественное число |
|---|---|---|
| На **-о (-o)** | село (selo) | села (sela) |
| На **-о (-o)** | слово (slovo) | слова (slova) |
| На **-е (-e)** | море (more) | мора (mora) |
| На **-е (-e)** | поље (polje) | поља (polja) |

Окончание **-е (-e)** в этом случае вызвано мягкостью предыдущего согласного.

### Особые правила наращивания корня вставками

### 3.1. Вставка «-ен- (-en-)»

Исторически эти слова заканчивались на носовой звук, который распался на **ЕН (EN)**.

| Единственное число | Множественное число |
|---|---|
| време (vreme) | времена (vremena) |
| племе (pleme) | племена (plemena) |

### 3.2. Вставка «-ет- (-et-)»

Обычно это предметы; часто такие слова имеют тюркское происхождение.

| Единственное число | Множественное число |
|---|---|
| дугме (dugme) | дугмета (dugmeta) |
| парче (parče) | парчета (parčeta) |

### 3.3. Вставка «-ћи- (-ći-)»

Используется для детенышей животных и людей.

| Единственное число | Множественное число |
|---|---|
| пиле (pile) | пилићи (pilići) |
| јаре (jare) | јарићи (jarići) |
| маче (mače) | мачићи (mačići) |

### 3.4. Вставка «-ес- (-es-)»

Используется в поэтических или возвышенных словах.

| Единственное число | Множественное число |
|---|---|
| небо (nebo) | небеса (nebesa) |
| чудо (čudo) | чудеса (čudesa) |

### 3.5. Особый случай: остаток двойственного числа

Остаток двойственного числа, которого больше нет, сохраняется для парных вещей.

| Единственное число | Множественное число |
|---|---|
| око (oko) | очи (oči) |
| ухо (uho) | уши (uši) |

### 3.6. Особый случай

| Единственное число | Множественное число |
|---|---|
| дете (dete) | деца (deca) |

## 4. Женский род

**Базовое правило:** для слов женского рода с окончанием **-а (-a)** окончание меняется на **-е (-e)**.

| Единственное число | Множественное число |
|---|---|
| жена (žena) | жене (žene) |
| кућа (kuća) | куће (kuće) |
| лутка (lutka) | лутке (lutke) |

### 4.1. Женский род с окончанием на согласную

Если слово женского рода заканчивается на согласную, к нему добавляется окончание **-и (-i)**.

| Единственное число | Множественное число |
|---|---|
| ствар (stvar) | ствари (stvari) |
| кост (kost) | кости (kosti) |
| реч (reč) | речи (reči) |

### 4.2. Женский род с окончанием на гласную «-о (-o)»

Если слово женского рода заканчивается на гласную **-о (-o)**, окончание меняется на форму с **-ли (-li)** по правилу «Беглое **А (A)** + переход **Л (L)** в **О (O)**».

| Единственное число | Множественное число |
|---|---|
| мисао (misao) | мисли (misli) |
| со (so) | соли (soli) |

### 4.3. Особые случаи из-за разных смыслов

| Единственное число | Множественное число | Значение                        |
| ------------------ | ------------------- | ------------------------------- |
| дрво (drvo)        | дрва (drva)         | дрова                           |
| дрво (drvo)        | дрвеће (drveće)     | деревья как растительность      |
| дрво (drvo)        | дрвета (drveta)     | отдельные деревья               |
| лист (list)        | листови (listovi)   | листы, страницы, отдельные листья |
| лист (list)        | лишће (lišće)       | листва                          |

## 5. Слова только множественного числа

Эти слова не изменяются по числам, потому что употребляются только во множественном числе.

| Слово | Значение |
|---|---|
| панталоне (pantalone) | брюки / штаны |
| маказе (makaze) | ножницы |
| наочаре (naočare) | очки |
| санке (sanke) | санки |
| мердевине (merdevine) | стремянка / лестница |
| врата (vrata) | дверь / двери |
| уста (usta) | рот |

### Согласование

- Если слово-исключение заканчивается на **-е (-e)**, воспринимайте его как группу женщин: `оне су... (one su...)`, `ове маказе... (ove makaze...)`.
- Если слово-исключение заканчивается на **-а (-a)**, воспринимайте его как группу сёл/окон: `она су... (ona su...)`, `ова врата... (ova vrata...)`.
